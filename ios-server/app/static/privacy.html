APP_OPERATOR_COMPANY（以下简称“我们”）运营“APP_NAME”。如果你对个人信息处理有疑问，或希望行使本政策所述权利，可发送邮件至 privacy@your-domain.example.com。本政策说明我们在提供地图导航、天气、罗盘、附近、出行助手、会员及广告服务时如何处理个人信息。

一、适用范围与处理原则

本政策适用于精准智能导航 iOS 应用及由我们提供的相关服务。我们只在实现明确功能所必需的范围内处理信息，并根据实际场景取得适用同意。阅读并同意本政策，不等于授予系统定位权限或同意跨 App 跟踪；这些选择分别由你作出。拒绝非必要处理，不影响可独立使用的核心功能。依赖位置、网络或购买资格的功能可能因相关条件不可用而受到影响。第三方独立提供的服务还适用其各自的隐私规则，相关接收方见第四节。

二、我们处理的信息与用途

  1. 基本使用与偏好。 为记住协议选择、引导完成状态和界面设置，我们在设备上保存相应记录与功能偏好。为维持服务及排查故障，处理必要的应用版本、设备和系统状态、请求时间、网络地址、错误码等技术信息；具体字段以实际产生的服务请求为限。
  2. 地点搜索、路线规划及导航。 当你输入目的地、选择起终点或发起导航，我们处理搜索词、地点及路线参数、出行方式和必要的请求状态。使用“我的位置”、附近或实时导航时，在你授权后处理当前的精确或近似位置、定位时间、方向以及导航期间为引导路线所需的位置变化。精确位置和行踪轨迹可能影响人身或财产安全，属于敏感个人信息；仅在实现相应功能确有必要时使用，并在处理前说明必要性、可能影响及取得依法要求的单独同意。手动输入地点、手选城市不统一要求定位授权。
  3. 天气与罗盘。 查询天气时，处理你选择的城市或地点标识；使用当前位置天气时，处理为查询所需的位置。罗盘使用设备方向和必要传感器信息显示朝向与校准状态；如需显示与地理北方有关的方向，按功能需要使用已授权的位置。不会因为手动查询天气而要求精确定位。
  4. 出行助手。 当你主动使用快捷问答或工具时，应用处理你输入的文字和当次操作所需状态，用于显示相关答复或功能指引。当前未接入 AI 模型服务；请不要在提问中输入证件号码、银行卡号、密码、健康资料等无关敏感信息。我们不默认把精确位置附加到你的提问。
  5. 订阅与恢复购买。 我们通过 Apple 应用内购买服务处理商品标识、交易标识、购买与到期时间、订阅、退款或撤销状态及验证结果，用于确认和恢复会员权益。支付由 Apple 处理，我们不获取完整银行卡号或 Apple 账户密码。
  6. 反馈与联系。 你主动通过应用或邮箱提交问题时，我们处理反馈内容、你提供的回复方式与排障所需信息，用于回复和解决问题。
  7. 广告展示与效果衡量。 应用已接入穿山甲广告 SDK 和广点通转化 SDK。广告 SDK 为加载、展示广告、衡量效果及识别异常流量，可能处理设备型号、操作系统与应用标识、网络状态及 IP 地址、IDFV、广告展示和交互记录、必要性能信息；广点通转化 SDK 按实际配置处理启动或购买等转化事件与必要的设备、应用信息。正式构建会在获得适用 ATT 授权后读取 IDFA，当前未开启个性化广告。广告 SDK 若使用位置或传感器，需先符合适用的必要性、告知和授权要求。

三、权限与系统选择

定位。 我们在你主动使用当前位置、附近、以当前位置为起点的路线、需要定位的天气或实时导航时，按需请求系统定位授权。你可在 iOS 系统提供的范围内选择使用期间、仅本次及精确或近似位置，并可在系统设置中变更或撤回。近似位置不等于拒绝；若功能确需更高精度，我们会说明。撤回后，依赖位置的功能可能无法继续；手动地点或城市输入在适用时仍可用。定位服务关闭、系统限制、弱信号、定位超时和权限拒绝是不同状态，应用应分别提示。

网络。 地图、天气、助手和购买核验需要联网。网络断开、弱网或超时是连接状态，不是 iOS 的统一“互联网访问权限”；我们不会为普通联网申请局域网权限。

跟踪（ATT）。 本应用为广告效果衡量和转化归因，会在访问 IDFA 或开展跨 App 跟踪前说明用途并按 iOS 规则请求 ATT 授权。未获得授权时，不读取 IDFA，不开展需要该授权的处理，也不以其他标识符或设备指纹绕过你的选择。你可在系统设置中管理跟踪授权；拒绝不会阻止导航、天气等可独立使用的功能，也不影响已购权益。广告展示与跨 App 跟踪不是同一件事。

当前产品没有推送、拍照、图片上传或语音输入功能，不因导航语音播报而申请麦克风或语音识别权限。只有用户主动开始的导航确需持续定位且完成相应告知与系统授权时，才在行程中按必要范围处理位置；行程结束后停止。

四、第三方服务与信息提供

为完成你使用的功能，我们接入以下服务。我们不出售你的个人信息。相关 SDK 可能在设备上采集并向服务提供方传输必要信息；通过 API 调用的服务则按实际调用链路传递查询参数。涉及依法须单独同意的敏感信息处理或向其他个人信息处理者提供信息时，我们会另行取得适用同意。各服务提供方还会按其隐私政策处理收到的信息。

  1. 高德开放平台导航 SDK（iOS）；提供方：北京高德图强科技有限公司。用途：地图展示、地点及周边查询、当前位置、路线规划和导航。按你使用的具体功能处理必要的位置及定位状态、搜索词、起终点和出行方式，以及 SDK 运行所需设备、系统、网络信息。使用依赖位置的功能时按系统授权范围处理。提供方政策：高德开放平台隐私政策。
  2. 和风天气 API；提供方：和风互联科技（北京）有限公司。用途：取得天气、预报及日出日落等查询结果。按你选择的查询方式传递城市或地点标识，或为当前位置查询所需的坐标、日期及查询参数。提供方政策：和风天气隐私政策。
  3. Apple App Store 应用内购买 / StoreKit；提供方：Apple 及其在适用地区提供 App Store 服务的关联主体。用途：购买、交易处理、权益验证及恢复。处理商品和交易标识、购买及到期信息、订阅/退款/撤销状态与必要的验证信息。提供方政策：Apple 隐私政策。
  4. 穿山甲广告 SDK（iOS）；提供方：北京巨量引擎网络技术有限公司及其关联方。用途：加载和展示广告、衡量广告效果、识别异常流量及维护服务稳定。按实际启用的广告功能处理必要的设备/系统和应用信息、IP 地址与网络状态、IDFV、广告展示及交互信息、性能信息；获得适用 ATT 授权后可处理 IDFA。位置及传感器是该 SDK 可配置的处理范围，是否启用应以本应用实际配置为准。提供方政策：穿山甲广告 SDK 隐私政策。
  5. 广点通转化 SDK（iOS）；提供方：深圳市腾讯计算机系统有限公司。用途：广告转化归因、效果衡量与渠道优化。按实际配置处理设备型号与系统、应用标识和状态、网络信息、IDFV 及选择回传的转化事件；IDFA 须在适用 ATT 授权后处理。其官方政策披露了内嵌风险识别组件；该组件的使用范围以本应用实际接入版本为准。提供方政策：腾讯广告广点通转化 SDK 隐私政策。

若新增第三方接收方或改变用途，我们会先更新本政策并完成适用告知与同意，不以笼统的“合作伙伴”替代具体披露。因合并、分立、解散等发生个人信息转移时，我们会依法告知接收方名称和联系方式，要求其继续承担保护义务；接收方改变原处理目的或方式的，依法重新取得同意。

五、广告与跟踪选择

广告展示、个性化广告、转化事件回传和跨 App 跟踪是不同处理活动。当前未启用个性化广告；穿山甲与广点通只应按正式构建开启的功能处理必要信息。读取 IDFA 或开展跨 App 跟踪，以 ATT 授权为前提；拒绝后仍可使用非跟踪的广告与基本服务。位置和设备传感器不能仅因接入广告 SDK 就默认用于广告；若实际启用，需符合必要性、告知及相应授权要求。

六、保存期限与安全

在中国大陆境内采集并由我们存储的用户信息仅保存在境内服务器，不由我们主动开展跨境传输。Apple 独立提供的应用内购买服务按其隐私规则处理相关信息；Apple 的中国大陆隐私政策说明指出，相关信息可能被其境外关联实体传输或访问，本应用的境内存储安排不代替 Apple 自身的处理规则。

我们在完成导航、天气、广告效果衡量、故障监测等各项具体目的所需的最短期间内保存相应信息，法律法规另有要求的除外。保存在设备上的协议与偏好记录通常随你清除应用数据或卸载而删除，但系统备份行为可能由设备设置决定。导航位置/路线、助手文本、反馈、广告与故障信息、订阅权益记录不会因一次使用而无限期保存；各类信息的具体保存期限须按正式服务配置确定后向你明确告知。依法应留存的网络运行和安全事件日志不少于六个月，仅在法定必要范围内使用；该要求不代表其他个人信息统一保存六个月。期限届满后删除或彻底匿名化；仍可关联到个人的去标识化数据不等于已匿名化。依法必须继续保存的，限制其他用途并采取保护措施。

我们采用与数据风险相适应的访问控制、传输保护、权限管理与安全措施。若发生个人信息安全事件，我们将采取补救措施并依法履行告知、报告义务。第三方服务提供方的处理范围和存储安排以实际传输链路及其政策为准；在确认任何境外接收方前，我们不会开展相应传输，如日后确有必要，将先履行适用的告知、同意及其他法定要求。
