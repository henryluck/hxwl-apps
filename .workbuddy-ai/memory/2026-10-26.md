## 本机环境踩坑（重要）

1. **xcodegen 未装且 brew 装不上**（sandbox 拦 `/opt/homebrew/var/homebrew/locks`）。改用官方 release 包解压到 `/Users/gx/.workbuddy-ai/binaries/xcodegen/xcodegen/bin`，构建时 `export PATH=...:$PATH`。
2. **sandbox-exec 在本机不可用**（`sandbox_apply: Operation not permitted`，嵌套沙箱限制）。xcodebuild 解析 SPM 清单必走 sandbox-exec → 依赖解析失败。
   解法：`defaults write com.apple.dt.Xcode IDEPackageSupportDisableManifestSandbox -bool YES`（同时写了 `com.apple.dt.xcodebuild` 域）。已写入本机全局默认值。
   另加 `XBS_DISABLE_SANDBOXED_BUILDS=YES` 环境变量，构建阶段脚本也不再套沙箱。
3. **Xcode 26.1 已不支持 x86_64/Rosetta 模拟器**：factory.py 里模拟器默认 `ARCHS=x86_64` 的产物无法安装（`Failed to find matching arch`）。本包 spec.json 的 integrations.crash.provider 为空、没引 Bugly，所以直接 `ARCHS=arm64` 可正常链接并通过装机验证。后续本机出包建议走 arm64。
4. **AppIcon 尺寸不合规**：`Resources/Assets.xcassets/AppIcon.appiconset/icon.png` 原为 1254×1254，actool 报 "did not have any applicable content" 导致构建失败。已用 `sips -z 1024 1024` 改为 1024×1024（原图备份 /tmp/icon-1254-backup.png）。
5. **版本号硬编码**：`FactoryCore-Info.plist` 由 xcodegen 从 `project.yml` 的 `info.properties` 生成，手改会被覆盖。已在 `project.yml` 加 `CFBundleShortVersionString: $(MARKETING_VERSION)` / `CFBundleVersion: $(CURRENT_PROJECT_VERSION)`，现在包内为 1.0.0 (1)，与 spec.json 一致。

## 订阅功能现状复盘（分析，未改代码）

已实现：spec 双套餐配置、StoreKit 2 全链路（加载/购买/重试一次/交易监听/finish/权益刷新/恢复）、isPro + ownsLifetime、订阅页三入口（引导末页/功能拦截/我的）、软付费墙、挽留页能力、中台验单挂钩。

主要缺口（按优先级）：
1. 零免费额度——搜索/周边/算路/开始导航/罗盘/海拔/天气/工具全部 requireMembership，仅地图可看（审核 3.1.1/4.2 与转化双风险）
2. 冷启动不再自动弹订阅页：`tryTriggerPaywall` 条件 `hasSubscriptionHistory || (!seenPaywall && !hasOnboarding)`，本包有 3 页引导 → 叉掉一次后永不自动弹
3. 全工程零业务埋点（无 `.track(` 调用），订阅漏斗完全不可观测
4. `trial_days: 3` 未生效（strategy=intro_price），与 ASC 若配试用会文案/实扣不一致
5. 中台 aesKey/aesIv 为空 → `TianxAES` 抛 invalidKeyLength，验单被 `try?` 静默吞掉，服务端验单实际未生效
6. `AnyPayService` 不转发 objectWillChange → Transaction.updates 异步到账时 UI 不刷新
7. 无 .storekit 配置，本地/CI 无法跑购买；单测仅 PaywallConfigTests 两条
8. 价格兜底策略：非中国店面回退 spec 的 ¥，存在展示价≠实扣价隐患
9. 定价口径：周续费 ¥48（年化 ¥2496）vs 终身 ¥188，买断价低于一个月订阅，需确认是否有意
10. SettingsView 在本包是死代码（nav_kit ownsTabBar 接管），改订阅入口容易改错位置
